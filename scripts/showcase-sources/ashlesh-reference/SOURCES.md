# Banking screens and visual reference collection

Source: https://ashleshgavas.vercel.app/ — Ashlesh Gavas. Retrieved 23 November 2026.

The user selected only Core Banking (3 screens), Internet Banking (4), Corporate
Banking (3), Mobile Banking (3), and Banner & Poster Design (12 designs).
Web Concepts and Urban Tobacco Machinery were explicitly excluded.

Original WebP images are retained without changing their interface content or
resolution in `src/showcases/references/`. The original source is credited in
each project view; the visual design collection is explicitly a reference
collection. No source résumé, personal experience claims, or performance
metrics are imported.

Hero composites use the existing photographic Apple device plates documented
in `../devices/SOURCES.md`. No generative mockup or invented UI is used. Long
screens are previewed from the top in hero devices; complete originals remain
scrollable in the gallery and available through full-resolution links.

To re-render: `python scripts/render-reference-heroes.py`.
The build only needs the checked-in source assets, not a network download.

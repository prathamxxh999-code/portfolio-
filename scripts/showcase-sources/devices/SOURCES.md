# Device plates

These are existing high-resolution hardware mockup templates, not AI-generated
images or procedurally drawn hardware. Interface screenshots and recordings are
composited beneath the original transparent display openings.

Downloaded from the primary MockUPhone repository on 2026-11-19:

- `macbook-pro-14.png`: 3944 × 2564 pixels, silver MacBook Pro 14.
  https://raw.githubusercontent.com/oursky/mockuphone.com/main/public/images/mockup_templates/apple-macbookpro14-front.png
- `iphone-15-pro.png`: 1419 × 2796 pixels, black titanium iPhone 15 Pro.
  https://raw.githubusercontent.com/oursky/mockuphone.com/main/public/images/mockup_templates/apple-iphone-15-pro-black-titanium-portrait.png

MockUPhone credits both device assets to Apple Design Resources:
https://mockuphone.com/deviceList/
https://developer.apple.com/design/resources/

Display coordinates come from MockUPhone's `src/scripts/device_info.json`.
The repository's Apache 2.0 license is included as `LICENSE-MockUPhone.txt`.

Added on 2026-11-23 for native 16:9 desktop interfaces:

- `imac-retina-front.png`: front-facing iMac Retina 2015, 2000 × 2000 pixels.
  https://raw.githubusercontent.com/oursky/mockuphone.com/main/public/images/mockup_templates/apple-imac2015retina-front.png
  Published display rectangle: x=154, y=318, width=1691, height=952.
  Existing source device metadata and repository license apply. It is a real
  hardware template. Compositing uses uniform scaling and viewport cropping;
  no synthesized screen padding or repeated edge pixels.

The CashBell capture uses its native dark theme. CRM retains its original
interface colours. Sample application records are not production results.
